# Akame Plugins

Plugins para servidores de Minecraft (Paper), hechos con cariño y probados en un servidor real antes de publicarse.

## Plugins

| Plugin | Descripción |
|---|---|
| **AkameDTC** | Evento *Destroy The Core*: un bloque que los jugadores golpean para sumar puntos, con ranking, recompensas persistentes y horarios automáticos. |

> Todos los plugins de la marca empiezan por **Akame**.
