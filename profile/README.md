# Akame Plugins

Plugins para servidores de Minecraft (Paper), hechos con cariño y probados en un servidor real antes de publicarse.

## Plugins

| Plugin | Descripción |
|---|---|
| **[AkameDTC](https://github.com/AkamePlugins/AkameDTC)** | Evento *Destroy The Core*: un bloque que los jugadores golpean para sumar puntos, con ranking, recompensas persistentes y horarios automáticos. |
| **[AkameCooldowns](https://github.com/AkamePlugins/AkameCooldowns)** | Bloqueos y cooldowns de items para Paper 1.21, globales o por región de WorldGuard: escudos, lanzas, perlas y cargas de viento bloqueados de verdad. |
| **[AkameAuctionPlus](https://github.com/AkamePlugins/AkameAuctionPlus)** | Addon de zAuctionHouse: compra rápida de un clic, catálogo con todos los objetos, transacciones, estadísticas y precio de venta en cada item. |
| **[AkameSell](https://github.com/AkamePlugins/AkameSell)** | `/sell` estilo DonutSMP: mete tus items, mira el total en una esquina y pulsa para vender, con multiplicadores por rango. |

> Todos los plugins de la marca empiezan por **Akame**.
